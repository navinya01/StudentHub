# 🎓 StudentHub – Student Productivity Dashboard

StudentHub is a web-based student productivity dashboard designed to help students organize their academic activities, access study materials, track habits, and monitor their academic progress in one place.

Our goal is to make student life more organized, productive, and efficient through a simple and user-friendly web application.

## ✨ Features

- 🏠 **Dashboard:** Access student productivity features from one place.
- 📚 **Study Resources:** Access learning materials and useful educational links.
- 🎯 **Habit Tracker:** Track daily habits and build consistent study routines.
- 📊 **Student Results:** View and monitor academic results.
- 🔐 **User Authentication:** Login and registration interfaces.
- 🔔 **Toast Notifications:** Display feedback messages for user actions.
